# 📱 CéCler Wallet - Guide d'Installation

Installez l'app CéCler Wallet directement sur l'écran d'accueil de votre téléphone en quelques secondes.

## ✨ Avantages de l'Installation

- 🚀 **Accès rapide** - Lancez l'app comme une app native
- 📴 **Mode hors ligne** - Accédez à vos documents même sans internet
- 🔒 **Sécurisé** - Toutes les données restent sur votre téléphone
- 💾 **Léger** - Moins de 5 MB après installation
- 🔄 **Mises à jour automatiques** - Toujours à jour sans App Store

---

## 📱 iPhone / iPad

### Étapes d'installation (3 clics)

#### **Étape 1️⃣** - Ouvrez le navigateur
Appuyez sur **Safari** sur votre écran d'accueil

#### **Étape 2️⃣** - Accédez au lien
Tapez ou scannez : **https://c-wallet.vercel.app**

#### **Étape 3️⃣** - Partager
Appuyez sur le bouton **Partager** (carré avec flèche vers le haut)
- Faites défiler vers le bas
- Appuyez sur **"Sur l'écran d'accueil"**
- Appuyez sur **"Ajouter"**

#### ✅ Fait !
L'app s'ajoute à votre écran d'accueil. Appuyez sur son icône pour la lancer.

---

## 🤖 Android

### Étapes d'installation (4 clics)

#### **Étape 1️⃣** - Ouvrez le navigateur
Appuyez sur **Chrome** ou **Firefox** sur votre écran d'accueil

#### **Étape 2️⃣** - Accédez au lien
Tapez ou scannez : **https://c-wallet.vercel.app**

#### **Étape 3️⃣** - Menu
Appuyez sur les **3 points** (menu) en haut à droite
- Cherchez **"Installer l'app"** ou **"Ajouter à l'écran d'accueil"**

#### **Étape 4️⃣** - Confirmer
Appuyez sur **"Installer"**

#### ✅ Fait !
L'app s'ajoute à votre écran d'accueil. Appuyez sur son icône pour la lancer.

## ❓ FAQ

**Q : L'app fonctionne-t-elle hors ligne ?**  
A : Oui ! Une fois installée, vous pouvez accéder à vos documents sans connexion internet.

**Q : Est-ce que je dois payer pour l'app ?**  
A : Non, c'est gratuit et toujours gratuit.

**Q : Où sont stockés mes documents ?**  
A : Tous vos documents restent sur votre téléphone. Aucun serveur externe.

**Q : Puis-je désinstaller l'app facilement ?**  
A : Oui, appuyez longtemps sur l'app et appuyez sur "Supprimer".

**Q : Ça fonctionne sur tous les téléphones ?**  
A : Oui, iPhone (iOS 12+) et Android (version récente).
